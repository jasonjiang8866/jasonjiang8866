# Jason Jiang

**ML Systems / AI Infrastructure**

I turn model experiments into reproducible GPU workflows and build services that other engineers can integrate. My background is in semiconductor manufacturing automation.

## Selected work

- **[waferVLM](https://github.com/jasonjiang8866/waferVLM)** — Built auditable wafer-map classification experiments with Qwen and DINOv3. Across three training seeds, DINOv3 vision LoRA improved accuracy over its paired frozen-backbone linear baseline by **+3.75 / +5.00 / +5.00 percentage points** on the same 160-map development set; **18/18 fresh-process evaluations (2,880 prediction records)** were verified. **Evidence:** [three-seed report](https://github.com/jasonjiang8866/waferVLM/blob/main/docs/dinov3-confirmation-results.md). *Separately, Qwen seed-17 step-250 reached [104/148 on held-out lots](https://github.com/jasonjiang8866/waferVLM/blob/main/docs/qwen-holdout-results.md); DINO holdout remains **0/888**. Development gains are not independent-test or cross-model superiority claims.*

- **[FlashAttentionAnyCard](https://github.com/jasonjiang8866/flashattentionanycard)** — Built reproducible Triton tuning and paired PyTorch baseline confirmation for GEMM, RMSNorm, and grouped MoE. **Real M1 GPU acceptance:** **25 correctness tests**, **18 tuning studies**, **108 fresh paired confirmation workers** on a **PRO 6000 Blackwell MIG 24 GB**; the Pod was independently confirmed absent. **Evidence:** [M1 GPU run](https://github.com/jasonjiang8866/flashattentionanycard/actions/runs/43917307722) · [independent cleanup](https://github.com/jasonjiang8866/flashattentionanycard/actions/runs/43920030853). *A small synthetic, single-device smoke/measurement protocol—not a cross-GPU speedup or production performance claim.*

- **[smbfileserver](https://github.com/jasonjiang8866/smbfileserver)** — Built a reusable **Go SMB client**, embeddable standard **`net/http` handler**, and authenticated HTTP gateway with **streaming-by-default HTTP/1.1+ single-file reads** and bounded resource use. **Evidence:** [real Samba and restricted-container integration CI](https://github.com/jasonjiang8866/smbfileserver/actions/runs/43739229025). *Core components are merged; [observability tooling](https://github.com/jasonjiang8866/smbfileserver/pull/9) is still in PR. Actual OpenShift cluster acceptance is pending.*

## More projects

- **[runpod-ci-broker](https://github.com/jasonjiang8866/runpod-ci-broker)** — Budgeted GPU placement, result verification, and owned-Pod recovery: live MIG/RTX 4090 CUDA smokes accepted ([4090 evidence](https://github.com/jasonjiang8866/runpod-ci-broker/actions/runs/44305716295)); M2 durable queue and placement/execution code is merged, while [two-task GPU handoff acceptance](https://github.com/jasonjiang8866/runpod-ci-broker/pull/35) remains pending.
- **[simplexLoRA-bench](https://github.com/jasonjiang8866/simplexLoRA-bench)** — Nine independent CUDA/int8 LoRA, SimplexLoRA, and DoRA training runs across three seeds, with paired metrics, gradient diagnostics, and verified cleanup ([results](https://github.com/jasonjiang8866/simplexLoRA-bench/blob/main/docs/results/dora-benchmark-41399541318.md)); three seeds are descriptive, not proof of general superiority.
- **[spleeterpt](https://github.com/jasonjiang8866/spleeterpt)** — Trainable PyTorch Spleeter port with converted 2/4-stem weights and bounded-memory inference; **~96.7% lower peak allocated CUDA memory** than this port's original path on 10-minute synthetic audio ([GPU measurements](https://github.com/jasonjiang8866/spleeterpt/blob/main/docs/bounded-memory.md)). Five-stem release remains blocked by numerical parity.
- **[MLsysZero2Hero](https://github.com/jasonjiang8866/MLsysZero2Hero)** — Bilingual, experiment-driven ML Systems and GPU kernel labs. E00 ran an **FP32 vector-add kernel on an RTX 4090** (257 outputs, zero maximum absolute error), with verified artifact upload and owned-Pod deletion ([E00 GPU run](https://github.com/jasonjiang8866/MLsysZero2Hero/actions/runs/44523422041)). *This is a correctness smoke, not a performance benchmark; further labs remain in development.*
- **[MiniMind zh2en agent](https://github.com/jasonjiang8866/minimind-zh2en-agent)** — LangGraph translation, validation and correction over a local vLLM-compatible API; [durable retries, audit and resumable processing](https://github.com/jasonjiang8866/minimind-zh2en-agent/pull/7) are in an unmerged Draft PR with synthetic/mock-HTTP validation, not a live translation-quality benchmark.
- **[PEFT classification recipes](https://github.com/jasonjiang8866/peft-fine-tuning-recipes-classification)** — Llama 8-bit LoRA classification recipes plus a Qwen3.5-0.8B Muon/AdamW GPU training harness. On an RTX 4090, both optimizers resumed from step 6 and matched uninterrupted 12-step training with **zero maximum absolute tensor difference** ([CUDA smoke evidence](https://github.com/jasonjiang8866/peft-fine-tuning-recipes-classification/actions/runs/44411232628)); the **200-step optimizer comparison timed out at 105 minutes**, so no performance winner is claimed.
