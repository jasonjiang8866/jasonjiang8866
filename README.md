# Jason Jiang

**ML Systems / AI Infrastructure**

I turn model experiments into reproducible GPU workflows and build services other engineers can integrate. My background is in semiconductor manufacturing automation.

## Selected work

- **[waferVLM](https://github.com/jasonjiang8866/waferVLM)** — Evaluated Qwen and DINOv3 wafer-defect classifiers with frozen data, hashed artifacts and three training seeds. DINOv3 LoRA outperformed its paired linear baseline on the **160-map development set** and on **148 unseen-lot maps**: **888/888 holdout predictions** verified; holdout accuracy gains **+1.35 / +8.11 / +3.38 pp** across seeds. **Evidence:** [frozen holdout results](https://github.com/jasonjiang8866/waferVLM/blob/main/docs/dinov3-holdout-results.md) · [Wafer Daily image explorer](https://jasonjiang8866.github.io/waferVLM/). *Only seed 42's within-seed holdout confidence intervals exclude zero; the DINO-vs-Qwen contrast is not conclusive or compute-matched.*

- **[FlashAttentionAnyCard](https://github.com/jasonjiang8866/flashattentionanycard)** — Built auditable Triton kernel tuning and paired PyTorch confirmation for GEMM, RMSNorm and grouped MoE. Real **Blackwell MIG 24 GB M1** acceptance passed **25 GPU tests, 18 tuning studies and 108 fresh paired workers**; the temporary Pod was independently verified absent. **Evidence:** [GPU acceptance run](https://github.com/jasonjiang8866/flashattentionanycard/actions/runs/43917307722) · [independent recovery](https://github.com/jasonjiang8866/flashattentionanycard/actions/runs/43920030853). *Synthetic single-device acceptance, not proof of a general speedup or cross-GPU transfer benefit.*

- **[smbfileserver](https://github.com/jasonjiang8866/smbfileserver)** — A reusable **Go SMB client**, embeddable standard **`net/http` handler**, and authenticated gateway with streaming-by-default HTTP/1.1+ single-file reads, admission limits and share/path policies. **Evidence:** [real Samba and restricted-container CI](https://github.com/jasonjiang8866/smbfileserver/actions/runs/43739229025). *The core is merged; [observability work](https://github.com/jasonjiang8866/smbfileserver/pull/9) remains in PR, and real OpenShift cluster acceptance is pending.*

## More projects

- **[runpod-ci-broker](https://github.com/jasonjiang8866/runpod-ci-broker)** — Budget-aware GPU selection, durable claims, verified artifacts and ownership-scoped cleanup. Two real queued GPU smoke tasks completed **sequentially through one shared slot**, with independent recovery ([GPU run](https://github.com/jasonjiang8866/runpod-ci-broker/actions/runs/44842622651) · [recovery](https://github.com/jasonjiang8866/runpod-ci-broker/actions/runs/44843153249)). *The generic paid-run CLI is still gated; these are CUDA memory smokes, not model benchmarks.*
- **[PEFT classification recipes](https://github.com/jasonjiang8866/peft-fine-tuning-recipes-classification)** — Qwen3.5-0.8B LoRA classification with real RTX 4090 AdamW/Muon training, checkpoint-resume verification and 200-step comparisons. A validation-based Muon learning-rate sweep and two confirmation seeds completed ([GPU evidence](https://github.com/jasonjiang8866/peft-fine-tuning-recipes-classification/actions/runs/45010941362)); results are sensitive to learning rate and seed, with no general optimizer winner established.
- **[simplexLoRA-bench](https://github.com/jasonjiang8866/simplexLoRA-bench)** — Nine independent CUDA/int8 LoRA, SimplexLoRA and DoRA runs across three seeds, with paired test metrics, gradient diagnostics and verified Pod cleanup ([benchmark report](https://github.com/jasonjiang8866/simplexLoRA-bench/blob/main/docs/results/dora-benchmark-41399541318.md)). *Three seeds are descriptive, not proof of general superiority.*
- **[spleeterpt](https://github.com/jasonjiang8866/spleeterpt)** — Trainable PyTorch Spleeter port with converted 2/4-stem weights and bounded-memory long-audio inference: **~96.7% lower peak allocated CUDA memory** than this port's original path on 10-minute synthetic audio ([measurements](https://github.com/jasonjiang8866/spleeterpt/blob/main/docs/bounded-memory.md)). Five-stem CPU parity improved across two hosted architectures, but [bounded CUDA integration](https://github.com/jasonjiang8866/spleeterpt/pull/52) and release acceptance remain pending.
- **[MLsysZero2Hero](https://github.com/jasonjiang8866/MLsysZero2Hero)** — Bilingual, experiment-driven GPU and ML Systems labs. E00 verified a **257-element FP32 vector-add kernel on RTX 4090**, the result artifact receipt and Pod cleanup ([E00 run](https://github.com/jasonjiang8866/MLsysZero2Hero/actions/runs/44523422041)); [E01 profiling exercises](https://github.com/jasonjiang8866/MLsysZero2Hero/pull/8) are in PR, not hardware-accepted.
- **[MiniMind zh2en agent](https://github.com/jasonjiang8866/minimind-zh2en-agent)** — LangGraph translation → validation → correction over a local vLLM-compatible API. [Durable retries, source-order auditing and resumable processing](https://github.com/jasonjiang8866/minimind-zh2en-agent/pull/7) remain in an unmerged Draft PR, tested with simulated HTTP failures rather than live translation-quality benchmarks.
